# Refract Roadmap

Static, read-only public roadmap for Refract. Suggestions and vote counts come
from Discord; voting and discussion stay on Discord.

The site has no build step and is served directly by GitHub Pages. For a local
preview, serve this directory over HTTP and open `index.html`. `roadmap.json` is
generated by the private Refract bot repository and will later be refreshed by
the VM every six hours.

Shipped entries with a verified delivery month are shown newest first. Older
entries without a recoverable delivery date are kept visible in the final
`Earlier` section.
